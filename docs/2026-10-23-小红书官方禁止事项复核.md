## 4.2 已禁用行为

| 官方类别 | 结果及证据 |
| --- | --- |
| 网页联网请求 | 无 fetch/XHR/sendBeacon；HTML 引用及动态图标映射全部指向包内资源，CSS 无外部资源引用 |
| eval / new Function | 无调用 |
| WebAssembly | 无引用或调用 |
| iframe / object / embed | 无静态标签或动态创建 |
| 表单跳转提交 | `app.js` 在页内动态创建自定义条目表单；submit 处理器首先调用 `e.preventDefault()`，不调用 form.submit、不设置 action 或进行 location 导航 |
| Flash 等插件 | 无对应资源或调用 |
| a[download]、blob 下载 | 无 download 属性或赋值，无 Blob / createObjectURL 下载；`platform.js` 使用 writeTempFile → saveImageToPhotosAlbum |
| 打开外链或新窗口 | 无 target=_blank、window.open、location 跳转；来源网址为 `catalog.js` 的 JSON 元数据，详情只显示文字，不创建超链接；图标实际使用包内路径 |
| 跳转其他小工具 | 无对应链接及跳转能力 |
| 长按菜单 | 没有业务功能依赖系统长按菜单；卡片 contextmenu 事件被阻止，另有 CSS touch-callout 禁用处理 |

分享使用公开平台能力 `window.xhs.miniTool.postNote`，不通过浏览器新窗口、外链或下载来实现。保存相册仅在点击“保存当前页”后触发，分享仅在点击“分享到小红书”后触发；无读取用户相册代码。
