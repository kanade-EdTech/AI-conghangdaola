# 结果图模型名称分行

版本：0.1.3。日期：2026-10-24。

## 处理

网页卡片由 CSS 按宽度换行，但生成图片由 Canvas 独立绘制，之前仅按字符宽度切行，未保留品牌与版本的分段。因此网页有分行而结果图没有对应效果。

本次只在 `src/ai/poster.js` 的模型名称绘制中增加分段：

- Claude 名称第一行固定为 `Claude`，下一行显示完整后缀，如 `Opus 5.5`、`Sonnet 5.5`、`3.7 Sonnet`。
- DeepSeek 带后缀的型号，第一行显示品牌与基础版本，如 `DeepSeek V4.1`，下一行显示 `Flash 1017`；同样适用于 `Flash 0423`、`Pro 0423`、`Terminus` 和日期版本等。
- 每段仍有原有宽度检查，较长自定义名称继续自动换行。App 名称和其他模型沿用原逻辑。保留原字形、字号、行距、行高、归档副标题、分页和像素预算。
- Toy 保存图片及小红书保存/分享使用相同的图片绘制代码，因此两端均包含修复。

不修改真实条目名称、ID、搜索、网页卡片 DOM、存储或排名；原有存档继续沿用。

## 验证

- 47 项自动测试通过，新增三项 Canvas 名称绘制验证：Claude 分行基线、DeepSeek 版本/后缀位置与两种画质、其他名称及较长后缀回归。
- 18 项实际浏览器检查通过：Toy/小红书 × Claude/DeepSeek × 1080/720；核对所有同品牌型号实际 `fillText` 的分行位置、PNG 解码和像素预算、无脚本异常。
- 实际页面“生成结果图”的输出已目视确认：`output/playwright/ai-poster-claude-lines.png`、`output/playwright/ai-poster-deepseek-lines.png`。
